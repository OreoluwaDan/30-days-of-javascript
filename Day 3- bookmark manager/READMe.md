# Day 3 — Bookmark Manager

A simple Bookmark Manager built as part of my 30 Days of JavaScript challenge.

## About the Project

The Bookmark Manager helps users save website links with a title and tags, making it easier to organize and find useful resources later.

Instead of searching through browser history or old conversations, users can search their saved bookmarks or click a tag to find related links.
